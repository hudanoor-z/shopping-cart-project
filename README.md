# 🛒 Shopping Cart Project

A simple e-commerce shopping cart built using **HTML, CSS, and JavaScript (DOM Manipulation).

## 🚀 Features
- Add items to cart
- Remove items from cart
- Increase / decrease quantity
- Automatic total price calculation
- Dynamic UI updates

## 🧠 What I Learned
- Working with arrays and objects
- DOM manipulation in JavaScript
- Handling user interactions (buttons, events)
- Updating UI dynamically based on data
